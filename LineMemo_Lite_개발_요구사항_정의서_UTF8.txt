개발 요구사항 정의서
프로젝트명: LineMemo Lite
작성일: 2026-05-05
문서 버전: v0.1

1. 개요

LineMemo Lite는 사용자가 여러 줄로 된 메모를 붙여넣은 뒤, 의미별 탭으로 나누고, 카드 단위로 묶고, 줄 단위로 빠르게 복사할 수 있게 해주는 초경량 로컬 메모 앱이다.

일반 메모앱처럼 긴 문서를 작성하는 것이 목적이 아니라, 계정 정보, URL, SSH 명령어, API 호출 예시, 코드 조각, 프롬프트, 업무 문구처럼 각각 한 줄마다 의미가 있는 값을 관리하고 필요한 줄만 복사하는 것이 핵심 목적이다.

2. 핵심 목표

2.1 제품 목표

- 여러 줄 메모를 줄 단위로 관리할 수 있어야 한다.
- 탭을 통해 의미상 분리가 가능해야 한다.
- 하나의 업무 묶음은 카드 단위로 관리되어야 한다.
- 각 줄은 개별 복사가 가능해야 한다.
- 여러 줄을 선택하여 한 번에 복사할 수 있어야 한다.
- 구분선 기준으로 블록 복사가 가능해야 한다.
- 모든 데이터는 로컬에 저장되어야 한다.
- 외부 서버로 데이터가 전송되지 않아야 한다.
- 메모리 사용량은 최소화되어야 한다.
- 앱은 쉽게 열 수 있어야 한다.

2.2 비목표

아래 기능은 초기 버전에서 제외한다.

- 클라우드 동기화
- 로그인
- 회원 관리
- 팀 공유
- 파일 첨부
- 마크다운 에디터
- AI 자동 분류
- 명령어 직접 실행
- 터미널 내장
- 비밀번호 관리자 수준의 보안 기능
- 복잡한 폴더/하위폴더 구조
- 데이터베이스 기반 대형 검색 시스템

3. 사용자 시나리오

3.1 여러 줄 접속 정보 관리

사용자는 다음과 같은 내용을 하나의 카드에 붙여넣는다.

예시:

계정 이메일
비밀번호 또는 토큰
클라이언트 URL
---
ssh -L 5678:localhost:5678 user_remote
추가 메모

앱은 이를 줄 단위 항목으로 나누어 보여준다. 사용자는 필요한 줄만 복사하거나, 구분선 기준으로 블록을 복사할 수 있다.

3.2 탭별 의미 분리

사용자는 메모를 다음과 같은 탭으로 분리한다.

- Inbox
- 계정/접속
- SSH/서버
- API
- 코드
- 프롬프트
- SQL
- 업무문구
- 기타

탭은 복잡한 폴더 구조가 아니라, 가볍게 의미를 나누는 필터 역할을 한다.

3.3 줄 단위 복사

각 줄 오른쪽에 복사 버튼이 있다. 사용자가 버튼을 누르면 해당 줄의 값만 클립보드에 복사된다.

예시:

라벨: 터널링
값: ssh -L 5678:localhost:5678 user_remote

복사 결과:

ssh -L 5678:localhost:5678 user_remote

3.4 선택 복사

사용자는 여러 줄을 체크한 뒤 선택 복사를 누를 수 있다.

예시 선택 항목:

- 계정 이메일
- 클라이언트 URL
- SSH 명령어

복사 결과:

계정 이메일 값
클라이언트 URL 값
SSH 명령어 값

3.5 블록 복사

카드 내부에 구분선("---")이 있을 경우, 구분선 사이의 줄들을 하나의 블록으로 간주한다. 사용자는 특정 블록만 복사할 수 있다.

4. 정보 구조

4.1 기본 구조

앱의 데이터 구조는 다음 3단계로 구성한다.

Tab
  Card
    Line Item

4.2 Tab

탭은 메모를 의미상 분리하는 최상위 단위이다.

필드:

- id: 탭 고유 ID
- name: 탭 이름
- order: 표시 순서

기본 탭:

- 전체
- Inbox
- 계정/접속
- SSH/서버
- API
- 코드
- 프롬프트
- SQL
- 업무문구
- 기타

4.3 Card

카드는 하나의 업무 묶음 또는 접속 정보 묶음을 의미한다.

필드:

- id: 카드 고유 ID
- tabId: 소속 탭 ID
- title: 카드 제목
- description: 간단 설명
- items: 줄 항목 목록
- createdAt: 생성일
- updatedAt: 수정일
- favorite: 즐겨찾기 여부

예시 카드:

- sota21 원격 접속
- OpenAI API 호출 템플릿
- FastAPI 로컬 실행 순서
- 자주 쓰는 SQL
- 회의록 정리 프롬프트

4.4 Line Item

Line Item은 실제 복사 대상이 되는 한 줄 또는 구분선이다.

필드:

- id: 줄 고유 ID
- label: 줄의 의미
- value: 실제 값
- type: 항목 유형
- secret: 민감정보 여부
- order: 카드 내부 순서

type 후보:

- text
- url
- command
- code
- divider
- note

secret이 true인 줄은 화면에서 기본적으로 마스킹한다.

예시:

label: 비밀번호
value: 실제 비밀번호
type: text
secret: true

화면 표시:

비밀번호    ********    [복사]

5. 기능 요구사항

5.1 탭 관리

필수 기능:

- 기본 탭 제공
- 탭 추가
- 탭 이름 수정
- 탭 삭제
- 탭 순서 변경

제약:

- "전체" 탭은 삭제할 수 없다.
- "전체" 탭은 모든 카드 검색 및 조회용 필터이다.
- "Inbox" 탭은 기본 임시 저장소로 제공한다.

5.2 카드 관리

필수 기능:

- 카드 생성
- 카드 수정
- 카드 삭제
- 카드 제목 변경
- 카드 탭 이동
- 카드 즐겨찾기
- 카드 전체 복사

카드 생성 방식:

- 빈 카드 생성
- 여러 줄 붙여넣기로 카드 생성

5.3 여러 줄 붙여넣기

사용자가 여러 줄 텍스트를 붙여넣으면 앱은 자동으로 줄 항목을 생성한다.

처리 규칙:

- 줄바꿈 기준으로 항목을 나눈다.
- 빈 줄은 기본적으로 제외한다.
- "---"만 있는 줄은 divider 타입으로 처리한다.
- "http://" 또는 "https://"로 시작하면 url 타입으로 추정한다.
- "ssh", "curl", "python", "pip", "npm", "uvicorn" 등으로 시작하면 command 타입으로 추정한다.
- 나머지는 text 타입으로 처리한다.

자동 추정은 보조 기능이며, 사용자가 나중에 타입을 수정할 수 있어야 한다.

5.4 줄 관리

필수 기능:

- 줄 추가
- 줄 수정
- 줄 삭제
- 줄 순서 변경
- 줄 라벨 수정
- 줄 타입 수정
- secret 여부 설정
- 줄 단위 복사

5.5 복사 기능

복사 기능은 앱의 핵심 기능이다.

필수 복사 방식:

- 줄 복사
- 선택 복사
- 카드 전체 복사
- 블록 복사
- 라벨 포함 복사
- 값만 복사

기본값:

- 터미널 명령어, URL, 코드 조각은 값만 복사한다.
- 업무 공유용 메모는 라벨 포함 복사를 선택할 수 있다.

5.6 블록 복사

divider 타입 항목을 기준으로 카드 내부를 여러 블록으로 나눈다.

예시:

계정
비밀번호
URL
---
SSH 명령어
서버 메모

블록 1:

계정
비밀번호
URL

블록 2:

SSH 명령어
서버 메모

각 블록 옆에 복사 버튼을 제공한다.

5.7 검색

검색 대상:

- 카드 제목
- 카드 설명
- 줄 라벨
- 줄 값
- 탭 이름

검색 방식:

- 입력 즉시 필터링
- 대소문자 구분 없음
- 전체 탭에서는 모든 탭의 카드 검색
- 특정 탭에서는 해당 탭 내부만 검색

5.8 민감정보 마스킹

secret이 true인 줄은 화면에서 기본적으로 값을 숨긴다.

표시 예시:

비밀번호    ********

필수 기능:

- secret on/off 설정
- 마스킹 상태에서도 복사 가능
- 값 표시 버튼 제공
- 값 표시 후 일정 시간 뒤 자동으로 다시 숨김

초기 버전에서는 암호화 저장을 필수로 하지 않는다. 단, 민감정보를 평문 JSON에 저장할 수 있다는 위험을 UI에서 명확히 알려야 한다.

5.9 로컬 저장

모든 데이터는 로컬 파일에 저장한다.

초기 저장 방식:

- JSON 파일

권장 저장 위치:

- Windows: %APPDATA%\LineMemoLite\data.json

백업 편의를 위해 사용자가 데이터 파일 위치를 확인할 수 있어야 한다.

필수 조건:

- 외부 서버 전송 없음
- 네트워크 요청 없음
- 자동 동기화 없음
- 로컬 파일 기반 저장
- 앱 재시작 후 데이터 유지

5.10 백업과 복원

초기 버전에서 최소 기능만 제공한다.

필수 기능:

- 데이터 JSON 내보내기
- 데이터 JSON 가져오기

제약:

- 가져오기 전에 기존 데이터를 백업한다.
- 잘못된 JSON 파일이면 가져오기를 중단한다.

6. 비기능 요구사항

6.1 경량성

이 앱은 메모리 사용량을 최소화해야 한다.

원칙:

- Electron 사용 금지
- 무거운 프론트엔드 프레임워크 사용 지양
- 초기 버전에서는 React 사용 지양
- DB 사용 지양
- 백그라운드 상시 실행 지양
- 불필요한 애니메이션 최소화
- 대형 라이브러리 사용 최소화
- 이미지 리소스 최소화
- 자동 인덱싱 기능 제외
- 네트워크 모듈 제외

권장 기술:

- Tauri
- Vanilla HTML/CSS/JavaScript
- 로컬 JSON 파일

목표 메모리 기준:

- 일반 사용 중 가능한 한 낮은 메모리 사용량 유지
- 대기 상태에서 불필요한 작업 없음
- 백그라운드 트레이 상주 기능은 초기 버전에서 제외
- 빠른 실행을 위해 앱 구조를 단순하게 유지

주의:

Tauri도 WebView2를 사용하므로 완전한 네이티브 앱보다 메모리 사용량이 있을 수 있다. 하지만 Electron보다 가볍게 만들 수 있고, 개발 생산성과 경량성의 균형이 좋다.

6.2 쉬운 실행

앱은 사용자가 쉽게 열 수 있어야 한다.

필수 조건:

- Windows 실행 파일 제공
- 더블클릭으로 실행 가능
- 별도 서버 실행 불필요
- 별도 터미널 명령어 불필요
- 로그인 불필요
- 첫 실행 시 바로 사용 가능

선택 기능:

- 바탕화면 바로가기
- 시작 메뉴 바로가기
- 최근 사용 탭 기억
- 마지막 열었던 카드 위치 기억

초기 버전에서는 트레이 상주와 전역 단축키는 제외한다. 이유는 빠른 접근성은 좋아지지만, 백그라운드 메모리 사용량이 증가하기 때문이다.

6.3 로컬 전용

앱은 로컬 전용 앱이어야 한다.

금지 사항:

- 서버 업로드
- 클라우드 동기화
- 원격 로깅
- 원격 분석
- 자동 업데이트를 위한 사용자 데이터 전송
- 외부 API 호출

허용 사항:

- 앱 업데이트 확인은 초기 버전에서 제외
- 사용자가 직접 파일을 내보내는 백업은 허용

6.4 보안

초기 버전은 비밀번호 관리자 앱이 아니다. 따라서 API Key, DB 비밀번호, 운영 토큰 등 매우 민감한 정보는 저장하지 않는 것을 권장한다.

초기 보안 기능:

- secret 마스킹
- 값 표시 후 자동 숨김
- 클립보드 복사 후 선택적 자동 삭제
- 로컬 저장 경고 문구

추후 보안 기능:

- 앱 잠금 비밀번호
- JSON 파일 암호화
- 마스터 비밀번호
- 클립보드 자동 삭제 기본 적용
- 민감정보 저장 전 경고

보안 원칙:

- 암호화 알고리즘을 직접 구현하지 않는다.
- 검증된 라이브러리만 사용한다.
- 명령어 직접 실행 기능은 초기 버전에서 제외한다.

6.5 성능

초기 데이터 규모 기준:

- 탭 20개 이하
- 카드 1,000개 이하
- 줄 항목 20,000개 이하

초기 버전에서는 이 정도 규모를 무리 없이 검색하고 표시할 수 있어야 한다.

성능 원칙:

- 전체 데이터를 한 번에 과도하게 렌더링하지 않는다.
- 검색 시 필요한 카드만 표시한다.
- 너무 많은 카드가 있을 경우 간단한 페이지네이션 또는 접기 기능을 검토한다.
- 저장은 변경 시점에만 수행한다.
- 자동 저장은 debounce를 적용한다.

7. 화면 요구사항

7.1 기본 화면

구성:

- 상단 검색창
- 탭 바
- 카드 목록
- 카드 내부 줄 항목
- 복사 버튼
- 선택 복사 버튼
- 새 카드 버튼

예시 화면 구조:

LineMemo Lite

[검색어 입력...]

[전체] [Inbox] [계정/접속] [SSH/서버] [API] [코드] [프롬프트] [SQL] [업무문구] [기타]

카드: sota21 원격 접속

[ ] 계정        user@example.com                         [복사]
[ ] 비밀번호    ********                                 [복사]
[ ] URL         example.apps.googleusercontent.com        [복사]
    ------------------------------------------------
[ ] 터널링      ssh -L 5678:localhost:5678 user_remote    [복사]

[선택 복사] [카드 전체 복사] [수정] [삭제]

7.2 카드 작성 화면

필드:

- 제목
- 탭 선택
- 설명
- 여러 줄 붙여넣기 영역
- 줄 목록 편집 영역

- secret 여부
- 순서

9. 기술 요구사항

9.1 권장 기술 스택

- Desktop Framework: Tauri
- Frontend: Vanilla HTML/CSS/JavaScript
- Storage: JSON file
- OS Target: Windows
- Network: 사용하지 않음

9.2 기술 선택 이유

Tauri를 추천하는 이유:

- Electron보다 가볍게 만들 수 있다.
- Windows 앱 형태로 배포 가능하다.
- HTML/CSS/JavaScript로 UI를 빠르게 만들 수 있다.
- 로컬 파일 저장 기능을 붙일 수 있다.
- 앱 크기와 메모리 사용량을 비교적 낮게 유지할 수 있다.

Vanilla JS를 추천하는 이유:

- React보다 초기 구조가 단순하다.
- 상태 관리 라이브러리가 필요 없다.
- 번들 크기를 줄일 수 있다.
- 개인용 경량 앱에 적합하다.

JSON 파일을 추천하는 이유:

- 구현이 단순하다.
- 백업이 쉽다.
- 사용자가 내용을 직접 확인할 수 있다.
- 초기 데이터 규모에서는 충분하다.
- DB 마이그레이션 부담이 없다.

9.3 제외 기술

초기 버전에서 제외한다.

- Electron
- React
- Redux
- SQLite
- 클라우드 DB
- Firebase
- Supabase
- 인증 서버
- 자동 업데이트 서버
- 원격 로깅 도구

단, 추후 데이터 규모가 커지면 SQLite 전환은 검토할 수 있다.

10. 저장 정책

10.1 저장 위치

기본 저장 위치:

%APPDATA%\LineMemoLite\data.json

백업 파일 위치 예시:

%APPDATA%\LineMemoLite\backup\data_YYYYMMDD_HHMMSS.json

10.2 저장 시점

- 카드 생성 시
- 카드 수정 시
- 카드 삭제 시
- 줄 수정 시
- 탭 수정 시
- 설정 변경 시

자동 저장은 너무 자주 발생하지 않도록 debounce를 적용한다.

10.3 데이터 손상 방지

저장 시 바로 원본 파일을 덮어쓰지 않는다.

권장 방식:

1. data.tmp.json에 먼저 저장
2. 저장 성공 여부 확인
3. 기존 data.json을 백업
4. data.tmp.json을 data.json으로 교체

11. 클립보드 요구사항

11.1 복사 동작

사용자가 복사 버튼을 누르면 해당 값이 클립보드에 저장된다.

복사 성공 시:

- 작은 알림 표시
- 버튼 텍스트를 잠시 "복사됨"으로 변경

11.2 클립보드 자동 삭제

초기 설정은 비활성화로 둔다.

옵션:

- 사용 안 함
- 10초 후 삭제
- 30초 후 삭제
- 60초 후 삭제

주의:

클립보드 자동 삭제는 사용자가 다른 값을 복사했을 때 그 값을 지워버릴 수 있으므로, 구현 시 마지막으로 앱이 복사한 값과 현재 클립보드 값이 같은 경우에만 삭제한다.

12. 사용성 요구사항

12.1 빠른 접근

초기 버전:

- 더블클릭 실행
- 마지막 탭 기억
- 마지막 검색어는 기억하지 않음

추후 버전:

- 전역 단축키

- 빠른 검색 팝업

단, 추후 기능은 메모리 사용량 증가 가능성이 있으므로 옵션으로 제공한다.

12.2 키보드 사용성

권장 단축키:

- Ctrl + F: 검색창 이동
- Ctrl + N: 새 카드
- Ctrl + S: 저장
- Esc: 편집 취소

- Ctrl + C: 선택한 줄 복사

14. 위험 요소와 대응

14.1 민감정보 평문 저장 위험

위험:

초기 버전에서 JSON 파일에 민감정보가 평문으로 저장될 수 있다.

대응:

- secret 마스킹 제공
- 민감정보 저장 경고 표시
- API Key, 비밀번호는 KeePassXC 같은 전용 도구 사용 권장
- 추후 버전에서 암호화 지원

14.2 기능 과다로 인한 무거움

위험:

메모앱, 비밀번호 관리자, 실행기, 클립보드 앱을 모두 만들려고 하면 무거워진다.

대응:

- v0.1은 복사 중심 기능만 구현
- 실행 기능 제외
- 동기화 제외
- DB 제외
- 탭-카드-줄 구조 유지

14.3 백그라운드 실행으로 인한 메모리 증가

위험:

트레이 상주, 전역 단축키 기능은 편하지만 메모리를 계속 사용한다.

대응:

- 초기 버전에서 제외
- 추후 옵션으로 제공
- 기본값은 비활성화

14.4 데이터 파일 손상

위험:

앱 종료나 저장 중 오류로 JSON 파일이 손상될 수 있다.

대응:

- 임시 파일 저장 후 교체
- 저장 전 기존 파일 백업
- 가져오기 전 JSON 검증

15. 최종 요약

LineMemo Lite는 다음 한 문장으로 정의할 수 있다.

탭으로 의미를 나누고, 카드로 업무 묶음을 만들고, 줄 단위로 필요한 값만 빠르게 복사하는 초경량 로컬 메모 앱.

초기 버전의 핵심은 다음이다.

- 가볍게 실행
- 쉽게 열기
- 로컬 저장
- 외부 전송 없음
- 탭별 분리
- 카드별 묶음
- 줄 단위 복사
- 선택 복사
- 블록 복사
- secret 마스킹

초기 개발에서 가장 중요한 원칙은 다음이다.

기능을 많이 넣는 것이 아니라, 자주 복사해야 하는 값을 빠르게 찾고 정확히 복사하는 흐름을 완성하는 것이다.
